# Báo cáo DOCX — nội dung cần viết

1. Trang bìa, thành viên và phân công.
2. Mục tiêu, yêu cầu và phạm vi.
3. Kiến trúc Client–Server, sơ đồ luồng.
4. Giao thức, định dạng message, IP/port và vòng đời kết nối.
5. Mô tả chức năng, xử lý lỗi và bảo mật cơ bản.
6. Thiết kế kiểm thử, kết quả đo thực tế và hạn chế.
7. Hướng dẫn chạy, kết luận và hướng phát triển.
