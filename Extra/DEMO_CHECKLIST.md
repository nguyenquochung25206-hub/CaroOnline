# Demo checklist

- [ ] Run server as a separate process.
- [ ] Run at least two client processes (preferably separate computers for LAN demo).
- [ ] Show IP/port configuration and connection status.
- [ ] Show create/join room and game synchronization.
- [ ] Demonstrate invalid move/error handling.
- [ ] Demonstrate abrupt disconnect and recovery.
- [ ] Show logs and real test results.
- [ ] Put video demo link in README.
